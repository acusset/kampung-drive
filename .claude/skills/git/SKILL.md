Use conventional commits.

Never use Claude as Co-Author.

For branches names, also follow conventional commits. For example, use `feat/feature-name` for new features, `fix/bug-description` for bug fixes, and `chore/task-description` for maintenance tasks.

When committing changes, write clear and concise commit messages that describe the purpose of the change. Use the imperative mood in your commit messages (e.g., "Add feature X" instead of "Added feature X").

Commit body should be concise.
