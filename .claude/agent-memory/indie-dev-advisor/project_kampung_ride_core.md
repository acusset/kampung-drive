Kampung Ride is a neighbourhood carpooling app for Singapore. Match residents in the same condo/HDB estate who commute the same route at the same time — same block, same destination, same schedule. No detours, no strangers from across the island. Positioning is explicitly against Grab (surge pricing) and against generic carpooling (strangers, detours).

**Why:** Supply-constrained two-sided marketplace where the differentiator is hyper-local trust (I know my neighbour) and route efficiency (no pickup detours). The core insight is that people in the same condo already share destinations and schedules and never talk.

**How to apply:** Frame all advice around two-sided marketplace dynamics — drivers are the constrained side, so growth strategy has to be driver-first even though riders will show up organically. Estate-level (not city-level) is the unit of network effect; a launch is per-estate, not per-city.
